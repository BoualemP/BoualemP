# Boualem Pereira

**Geophysicist turned Full-Stack & Data Developer** · 15+ years in seismic processing and oil & gas · Building web tools and data-driven solutions

For more than 15 years I ran end-to-end seismic processing, from field data to final image, with a focus on **depth imaging** and **quantitative analysis (AVO/AVA)**. I now apply the same habits (large, messy datasets, careful quality control, results that can be checked) to data analysis, machine learning and web development.

Open to freelance projects and to joining teams working on data, machine learning or web development.

## What I do

- **Websites (HTML5, CSS, JavaScript):** responsive landing pages and multi-page sites with contact forms, maps and basic SEO.
- **Python automation:** Excel processing, automated emails, APIs, web scraping and automated reports.
- **Data and machine learning:** data exploration, cleaning, analysis, reports and dashboards, predictive models.

## Projects
